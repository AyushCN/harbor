# Objectives

## Primary Objectives (v1)

1. Create environments from GitHub repositories with zero configuration
2. Every environment has a visible **Host**
3. Role-based access control (Owner / Collaborator / Viewer)
4. Share environments via links or direct invites
5. Real-time presence (see who is currently online in an environment)
6. Browser-based IDE with awareness of other collaborators
7. Live preview URL for every environment
8. Single-host reliability first

## Collaboration Specific Goals

- Dashboard must always show: Host name + avatar
- Inside the IDE: list of active collaborators
- Owner can promote/demote roles
- Collaborators can fork the environment into their own copy
